# DeadSawWhat_Scripts
Unity 3D 게임 제작을 목표로 진행된 3인 팀프로젝트입니다.

웨이브마다 몰려오는 적을 1인칭 슈터로 저지하는 게임입니다.

본 저장소는 저작권이 포함된 외부 에셋을 제외하고, 핵심 게임 로직을 담당하는 스크립트 위주로 구성된 Public Clone입니다.


## 개발 기간
2025.08.06 - 2025.08.25 (약 2주)


## 개발 인원
총 3명

- 김재언 (팀장)
  * 각 상태별로 부드럽게 전환되는 StateMachine 애니메이션 구조 제시
  * 적을 생성시키는 웨이브 시스템과 적 navMesh추적이동/공격/특수공격패턴 로직 설계
  * Photon PUN을 이용한 협력 멀티플레이 모드 제작
  * Perks를 통한 입장 전 부여가능한 플레이어 추가 스탯 기능
    
- 김경민 (팀원)
  * Unity의 InputSystem을 이용한 플레이어 조작
  * 사격/탄피 효과와 반동 연출, 스킬 사용 효과 구현
  * 인게임 내 아이템의 주기적인 생성 구조 및 각 효과 구현
    
- 박인우 (팀원)
  * 전체 UGUI 에셋 선택 및 적절한 레이아웃 배치
  * 스테이지 선택, 로딩창, 일시정지 등을 통한 각 Scene과 설정 조작기능
  * 현재 적의 웨이브와 플레이어의 체력/탄창 상태를 인게임 UI에 반영

## 플레이 과정 및 기능
### Main
1. 스테이지 선택을 통해 두 개의 맵중 하나를 선택하여 입장
2. Perks 창에서 본인이 원하는 스테이터스를 추가로 가지고 입장가능
3. Settings에서 마우스 감도와 소리 등을 설정

### InGame
1. 시작 시 우측에 조작키를 알려주며 F2키로 열거나 닫음
2. 총 5웨이브 동안 점점 많아지는 적들이 플레이어에게까지 닿기 전 사격으로 저지
3. 자연회복되는 스태미나를 통해 재장전하거나 스킬을 사용 가능
4. 약 20곳 정도의 빛나는 지점 위에 랜덤으로 체력 또는 탄창추가 아이템이 생성
5. 전부 저지 시 클리어이며 사망 시 실패 출력 후 Main으로 복귀
